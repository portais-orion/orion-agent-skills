# Relatório HTML de auditoria

Renderer consome somente o conjunto normalizado de findings e scorecards; não cria regra nem altera target. Produzir pt-BR, sem dependência pesada, com: resumo executivo, inventário, arquitetura, score/heatmap, findings filtráveis por sistema/categoria/severity/priority/classificação, evidência, `standardId`, roadmap e limitações runtime/organizacionais.

Cada finding mostra severity e priority em campos visuais separados. Valor sensível nunca aparece no HTML.
